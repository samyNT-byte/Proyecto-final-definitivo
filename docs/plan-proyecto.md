# Plan del proyecto MudanzaLimpia

## Objetivo
Crear una aplicación web responsive para que los clientes soliciten servicios de mudanza, aseo o el paquete “Departamento listo”.

## Páginas principales
1. Inicio: presentación del negocio y botón para solicitar servicio.
2. Servicios: catálogo con mudanza, aseo y paquete completo.
3. Cotización: formulario donde el cliente envía sus datos.
4. Administración: login del administrador y panel para ver solicitudes.

## Funcionamiento
1. El cliente abre la página.
2. Elige un servicio.
3. Llena el formulario de cotización.
4. Los datos se guardan en Firebase Firestore.
5. El administrador inicia sesión con Firebase Authentication.
6. El administrador revisa las solicitudes desde el panel.

## Tecnologías
- React para la interfaz.
- JavaScript para la lógica.
- CSS para el diseño responsive.
- Firebase Firestore para guardar datos.
- Firebase Authentication para el login.
- Git y GitHub para el control de versiones.
- GitHub Pages para publicar la página.
